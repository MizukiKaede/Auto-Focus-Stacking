# 材质颜色一致性修复

## 问题与范围

2026-09-30，用户实际输出 `DSC00522_stack.jpg` 的纸面和红底产生大量斑块，`DSC09651_stack.jpg` 与 `DSC09712_stack.jpg` 的红底存在长条颜色不均。此前 `printed-edge-ownership-v2` 只处理白色印字附近的焦点归属，局部小框通过不能代表整片红底或整张背景通过。

这次复用实际输出缓存中持久化的完整分析：00522 为 50/51 帧，09651 为 41/59 帧，09712 为 47/80 帧。矩阵和选片保持不变，不重新构造分析。尤其 09712 实际是 47 帧，不能以此前的 46 帧正式实验替代。实际输入来源见 `diagnostics/colour_surface_repair_20260930/provenance/actual_analysis_summary.md`。

## 通用规则

`SurfaceToneHarmonizer` 在 RGB 融合前逐帧统一各材质的低频颜色。焦点响应和几何矩阵继续使用原图；印字及彩色外轮廓附近补充来源归属守卫，主体其余区域沿用原标签。此步骤有意校正 RGB 的宽区域偏差，不是逐像素无损优化。没有图名、产品编号、指定红色值或人工 ROI 分支。

1. 第一遍对所有对齐帧采集长边不超过 256px 的跨帧颜色范围。HSV 的六个粗色相区分颜色，灰度区分深色/普通彩色及暗/中/亮中性区域。只有同类区域具有足够跨帧变化支持时才启用该材质；相同输入直接返回原 RGB。
2. 以融合参考帧建立材质内颜色基线。统计尺寸宽高各半且不超过 3MP；彩色内核要求饱和度不低于该材质饱和度 75 分位的 90%，避免失焦白字晕影定义红底颜色。源帧和参考均使用同一内核规则，向内收缩对应全图 8px，再做同材质归一化高斯滤波，尺度为全图 32px，不把掩码外的其他颜色算进均值。纯材质颜色可向参考帧失焦晕影附近延伸，不要求参考类别逐像素相等。
3. 第二遍对各源帧计算与参考相同的全图 32px 尺度颜色场，将宽区域偏差加回原 RGB 后再按原标签融合。匹配滤波尺度避免把中尺度印刷图案误当色差；提前校正避免来源帧的亮度/颜色差成为锐利斑块轮廓。与失败 v1 相比，参考颜色场使用纯度过滤、可延伸的同材质归一化场和连续衰减，避免旧的类别硬相等及偏差 40 硬截断。细纹理来自焦点帧，不把整张参考照片作为输出。
4. 跨帧探针变化需在 3–40 之间，支持至少 64 像素且至少占该材质共同区域 1%。局部偏差 1–4 逐渐增加权重，20–40 连续衰减，超过 40 不校正；参考密度权重连续增加。全分辨率 3×3 邻域内类型不同的像素保留源 RGB，保护轮廓、白字与不同材质边界。
5. 第一遍探针不保留整组 RGB。参考颜色场按需缓存，每种材质最多一份，规模与帧数无关。第二遍沿用原缓存和两遍读取路径，没有额外源图解码或配准。

v1逐帧校正虽改善00522，但09651出现硬接缝；v2融合后校正仍有硬块；v3的纯度过滤与连续权重消除了预览中的硬块，但00522正式融合仍有淡雪花轮廓；v4只提前中性校正，纸面改善但彩色仍有轮廓及白字晕带；v5主红面改善，白字及外沿仍有碎块。v6–v9从旧错误标签起步，且颜色门控留下孔洞，均未通过。v11采用连续印字覆盖；v13排除纹理误保护；v15补充受漆色支持的截断墨色组件，但外沿来源评分缺少清晰度约束，09651新增晕影。最终 `material-source-tone-v16` 加入外轮廓焦点评分，23项定向检查及三组正式完整实图复核通过，源码默认已启用。

印字守卫 `printed-edge-ownership-v12-supported-ink` 用小连通域面积过滤保留细长白线，排除孤立亮点。普通墨色要求 RGB 最大最小通道差不超过45、灰度至少140；贴着图像边界且含抗锯齿混色的白字允许通道差不超过80，但组件周界至少60%须邻接强漆色，面积至少对应全图32px。该宽容限只用于获支持的白墨组件，避免把失焦金边当白墨。组件扩充彩色主体内部范围，保持外部白背景不被吞入。

先在真实印字边缘比较梯度与高频焦点评分，选可靠边缘种子；再连续传播该种子的清晰来源，覆盖白墨、抗锯齿过渡及附近漆色。颜色仅识别边缘，不切割最终覆盖范围。最大支持半径为全图128px，保留真实彩色纹理保护。Quality 生产路径在原始观察回调中采集证据，最后于纹理与外轮廓处理之后改标签，避免其它后处理再次拆开已修好的边。此项仅涉及印字附近的来源归属，不把整幅换成同一参考帧。

`SurfaceBoundaryOwnership` 在较大的彩色连通区域外轮廓采集颜色梯度，在真实边缘处乘上现成高频焦点评分的平方根，再沿最近物理边缘扩展来源排名，避免较深或较饱和的失焦片仅凭颜色跃变胜出。未加权的色度强度单独保留为可信度，使用原0.002覆盖门槛，焦点评分只参与排名。支持范围为64px、外侧允许8px；白字孔洞不作为外轮廓。跨帧联合保留真实彩色纹理；纹理低通σ=2的统计像素与颜色边界保持3σ净距（统计核心13×13腐蚀），避免白墨混入红漆低通后被误判为纹理。此项与材质色调开关一起启用，三组实图中的缺口、长外沿及齿形已复核。

该规则作用于Quality的gate/clean。源码默认 `quality_surface_tone=true`，后续图片沿用此规则；显式false可回退。应用空配置及缺少新键的旧配置也采用该默认值，实际StackMergeService到Quality后端的传递已确认。legacy/gain、Hugin不接入此修复。印字归属守卫继续单独工作，全局曝光增益保持关闭。本轮没有重打包可执行文件。
